# Stefano

My background is in business development, GTM, venture capital and tech M&A. At some point I started building my own tools for the work I was doing, and I kept going.

Most of my repos are private because they have client or personal data in them, so this page looks emptier than it is.

**What I'm working on**

- A personal CRM behind my website, with everyone I've met in the last few years, tiered by relationship
- Automations for outreach, follow-ups and notes, built with n8n, Make and Claude Code
- A voice-note pipeline: an iOS Shortcut sends notes from my phone to an inbox table, then I sort them
- An app for IPN, a network of Italian professionals abroad, where I also run the venture side: co-founder matching, startup incubation and an angel club we're starting

**Things I think about a lot**

- Early-stage investing and what makes a founding team work
- Tools that save time instead of adding another dashboard

You can reach me on [LinkedIn](https://www.linkedin.com/in/stefano-gentili/) or through [my website](https://www.stefanogentili.xyz).
